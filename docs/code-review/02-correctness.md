## 2. Business Flow State Machine Validation

### Enquiry Lifecycle Analysis
- Stages: `New` -> `Qualified` -> `Quoted` -> `Converted`
- Outcomes: `Open` vs `Lost`
- **Flaw Identified:** When an Enquiry reaches `Quoted`, the user can manually set `stage = 'New'` via PUT request because the server does not enforce `canAdvanceStage`.
- **Flaw Identified:** Deleting an enquiry checks for attached quotations, but allows deleting an enquiry with status `Converted` if no quotation record was relationally linked.

### Quotation Approval Lifecycle Analysis
- States: `DRAFT` -> `PENDING_APPROVAL` -> `APPROVED` / `REJECTED`
- **Flaw Identified:** Once `APPROVED`, a quotation can be updated with arbitrary line items and prices without triggering re-approval.
- **Flaw Identified:** A quotation created via `POST /api/quotations` with status `APPROVED` directly by any user setting `user_role=SUPER_ADMIN` cookie completely bypasses review.
